# Dragonbane: Skills

Core and weapon skills come from the core rules reference. Magic skills come from the *Book of Magic* rules reference.

| Name | Type | Attribute | Description |
| --- | --- | --- | --- |
| Acrobatics | Core | AGL | Jumping, climbing, balancing and similar manoeuvres. |
| Awareness | Core | INT | Detect sneaking with an opposed roll; notice emerging threats. A passive threat roll cannot be pushed. Each member of a group rolls separately and cannot help another. |
| Bartering | Core | CHA | On success, improve the price by 20%; on a Dragon, halve a purchase price or double a sale price; on a Demon, the other party refuses the trade. |
| Beast Lore | Core | INT | Identify animals or monsters and recall habits, abilities or weaknesses; success should reveal useful information. |
| Bluffing | Core | CHA | Convincing lies. An unconvincing claim gives a bane; an impossible claim fails automatically. |
| Bushcraft | Core | INT | Navigation, camps, cooking and surviving cold. |
| Crafting | Core | STR | Repair a damaged item, normally in one shift with appropriate tools. |
| Evade | Core | AGL | Dodge attacks and flee combat. |
| Healing | Core | INT | Save characters at 0 HP and aid recovery. |
| Hunting and Fishing | Core | AGL | Track and obtain food in the wilderness. |
| Languages | Core | INT | Understand foreign or ancient languages and writings. |
| Myths and Legends | Core | INT | Recall old stories, distant lands and links with the past. |
| Performance | Core | CHA | Sing, recite, joke or otherwise entertain. |
| Persuasion | Core | CHA | Convince an NPC to meet a stated, reasonable objective. If the request demands meaningful risk or sacrifice, oppose PERSUASION with the NPC's WIL. Monsters cannot normally be persuaded. |
| Riding | Core | AGL | Advanced riding manoeuvres and mounted combat. |
| Seamanship | Core | INT | Handle a vessel in challenging conditions and navigate by water. |
| Sleight of Hand | Core | AGL | Pick pockets, pick locks and perform fine manual work. |
| Sneaking | Core | AGL | Avoid detection. Normally a straight roll; oppose active searching with AWARENESS. Roll only when the character can see or hear the creature being avoided. In group sneaking, one failure reveals the entire group. |
| Spot Hidden | Core | INT | Search for concealed things. A precise declared search may receive a boon or automatic success. A search normally takes one stretch; each character gets one attempt in the same place. |
| Swimming | Core | AGL | Challenging swimming, diving and avoiding drowning. |
| Axes | Weapon | STR | Axes, including thrown axes. |
| Bows | Weapon | AGL | Bows, excluding crossbows. |
| Brawling | Weapon | STR | Unarmed attacks with fists, feet, teeth or claws. |
| Crossbows | Weapon | AGL | All crossbows. |
| Hammers | Weapon | STR | Warhammers, clubs, maces and similar blunt weapons. |
| Knives | Weapon | AGL | Knives and daggers, including when thrown. |
| Slings | Weapon | AGL | Slings. |
| Spears | Weapon | STR | Spears, tridents and lances, including thrown spears. |
| Staves | Weapon | AGL | Staves. |
| Swords | Weapon | STR | All swords. |
| Animism | Secondary | INT | Casts Animism spells: nature magic of healing, plants, animals and weather. Rank 3 and higher training normally requires skill 15 in Beast Lore, Bushcraft or Seamanship. |
| Demonology | Secondary | INT | Casts Demonology spells drawing on Chaos and demons. Training first requires admission to a cult or movement; ranks 3–5 can also be learned through a demonic pact. |
| Elementalism | Secondary | INT | Casts Elementalism spells commanding fire, water, air and earth. Rank 3 and higher training requires acceptance by an advanced academy, tutor or master. |
| Harmonism | Secondary | CHA (uses PERFORMANCE) | Not a separate skill: Harmonism spells are cast with PERFORMANCE, and PERFORMANCE advancement marks are spent to learn them. Requires PERFORMANCE 12 and a willing teacher; a character who did not start as a harmonist bard also needs Magic Talent. Harmonists cannot learn General Magic. |
| Illusionism | Secondary | INT | Casts Illusionism spells of deception, disguise and shadow. |
| Mentalism | Secondary | INT | Casts Mentalism spells of mind over body and matter. |
| Necromancy | Secondary | INT | Casts Necromancy spells of death and undeath. Training normally includes a lunar cycle of labour for each spell taught. |
| Symbolism | Secondary | INT | Casts Symbolism spells through traced, drawn or carved symbols; the method of creating the symbol sets casting time and duration. |
| Witchcraft | Secondary | INT | Casts Witchcraft spells of animals, prophecy and curses. Training is usually paid in service rather than coin. |
| Alchemy | Secondary | INT | Prepares alchemical recipes (the school's spells) into potions, poisons and other doses using a laboratory and ingredients. Alchemy has no magic tricks. |
| Enchanting | Secondary | INT | Binds enchanting spells into items. Learning it, including at character creation, requires CRAFTING 12. Enchanting has no magic tricks. |
| Dracomancy | Secondary | INT | Casts rank 6 dragon magic. Can only be learned during play, and only by a character who already knows at least one rank 5 spell from another school. Spells cost 6 WP per power level. |
